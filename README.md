# FarmGame

A React-based farm simulation game using Vite, Tailwind CSS, and shadcn/ui.

## Getting Started

1. Install dependencies:
   ```powershell
   npm install
   ```
2. Start the development server:
   ```powershell
   npm run dev
   ```
3. Open `http://localhost:5173` in your browser.
4. Run tests:
   ```powershell
   npm run test
   ```
5. Run lint checks:
   ```powershell
   npm run lint
   ```

## Project Structure
- `src/components/FarmSimCanvas.jsx`: Main farm simulation component
- `src/main.jsx`: App entry point
- `index.html`: Main HTML file
- `src/index.css`: Tailwind CSS entry

## Customization
- Paste your full FarmSimCanvas code into `src/components/FarmSimCanvas.jsx`.
- Configure Tailwind in `tailwind.config.js` as needed.
