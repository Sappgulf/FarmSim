# UI Text Standards

## Voice
- Cozy, clear, and player-helpful.
- Action labels should be explicit and short.

## Naming consistency
- Prefer **"decoration"** in player-visible copy (avoid shorthand drift).
- Use clear CTA labels (example: `Select Ready Crops`).

## Hint style
- One-time, contextual, and dismissible by behavior.
- Keep hints to a single sentence with a direct action suggestion.

## Updated examples
- `Selected decoration: ...`
- `Select Ready Crops`
- Decor onboarding tip shown once on first decor-mode use.
